# X3D Toggle

Community-built Linux utilities for managing AMD Ryzen X3D CPU scheduling and 3D V-Cache priority.

## Choose a project

- **[X3D Toggle v1](https://github.com/X3D-Toggle/x3d-toggle)** — Lightweight CLI and KDialog utility with automated control.
- **[X3D Toggle v2](https://github.com/X3D-Toggle/x3d-toggle-main)** — GTK4/libadwaita desktop interface, CLI, and automation backend.

X3D Toggle is Linux-only and is not affiliated with or endorsed by AMD.
