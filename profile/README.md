# X3D Toggle Community Project

Community-built Linux utilities for managing AMD Ryzen X3D CPU scheduling and 3D V-Cache priority.

## Choose a project

- **[X3D Toggle v1](https://github.com/X3D-Toggle/x3d-toggle)** — Lightweight CLI and KDialog utility with automated control.
- **[X3D Toggle v2](https://github.com/X3D-Toggle/x3d-toggle-main)** — GTK4/libadwaita desktop interface, CLI, and automation backend.

> [!CAUTION]
> **Security Notice — Linux Only (Beware of Fake Windows Releases):**
> **X3D Toggle is strictly a Linux-only application.** There is **no** Windows version, and this project will never distribute Windows executables. AMD develops their own software, **AMD 3D V-Cache Performance Optimizer Driver**, for use on Windows platforms, but it is **NOT** the same program as X3D Toggle.
